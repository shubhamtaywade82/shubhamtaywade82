## Featured work

A few projects that represent what I’m building now:

| Project | What it does |
|---|---|
| [**nexum**](https://github.com/shubhamtaywade82/nexum) | Autonomous software-engineering agent designed to take a task through to a pull request. Developer preview; not yet published to npm. |
| [**DhanHQ SDK**](https://github.com/shubhamtaywade82/dhanhq-sdk) | TypeScript SDK for DhanHQ v2, including REST, WebSocket, options analytics, and MCP integrations. |

| [**Contractful**](https://github.com/shubhamtaywade82/contractful-ts) | Contract-first HTTP and WebSocket clients with typed methods and resilient transport. Also available for [Ruby](https://github.com/shubhamtaywade82/contractful). |
| [**Axis Nexus**](https://github.com/shubhamtaywade82/axis-nexus) | Options-trading system and control plane built around DhanHQ. |
